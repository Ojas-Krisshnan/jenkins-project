# 📄 Project 05: Jenkins Reports & Automation Utilities

Tools and documentation for generating Jenkins execution reports.

## 📌 Contents
- **`generate_report.py`**: Python automation script for compiling build logs, test outputs, and screenshot references into structured execution reports (`.docx` / `.pdf`).
- **`Jenkins_Execution_Report.docx`**: Comprehensive execution report documenting setup, pipeline stages, job runs, build logs, and visual evidence.

## 🚀 Running Report Generator
```bash
python generate_report.py
```
