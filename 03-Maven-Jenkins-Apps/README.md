# 📦 Project 03: Maven Starter Projects & Jenkins SCM Applications

A collection of lightweight Java Maven starter projects designed for testing Jenkins Freestyle jobs, SCM polling, and Maven plugin integrations.

## 📁 Sub-Projects
- **`java-maven-junit-helloworld/`**: Java Maven application with JUnit 4/5 unit tests and integration tests (`HelloWithTestsIT`).
- **`maven-demo-app/`**: Standard Maven project structure (`App.java` and `AppTest.java`) configured for Jenkins freestyle builds.
- **`java-hello-world-with-maven/`**: Minimal Maven Hello World repository used in Jenkins SCM trigger jobs (`Build-From-GitHub` and `Build-Maven-Project`).

## 🛠️ Build Commands
```bash
mvn clean compile
mvn test
mvn package
```
